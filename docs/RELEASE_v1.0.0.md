```markdown
# KeyFlow v1.0.0 — Standalone macOS Release

**KeyFlow** (formerly Codex Switch) is a native macOS menu bar app and command-line utility built to solve account-switching limits for developers using the official **Codex Desktop** app (ChatGPT client).

---

## 🚀 Key Features

* **1-Click Swapping**: Hot-swap Codex configurations instantly from the status bar menu.
* **Smart Session Priming**: Guard weekly/5-hour ChatGPT limits with proactive session warming.
* **Data Safety**: Built-in POSIX file-locking mechanisms to prevent concurrent write conflicts.
* **WCAG AA Compliant UI**: Sleek translucent popover with tier-colored visual feedback.
* **Zero Dependencies**: Out-of-the-box native binary execution—no node/bun runtime required on the client machine.

---

## 📦 Installation & Setup

1. Download **`KeyFlow.dmg`** below.
2. Open the DMG and drag **`KeyFlow.app`** to your **`Applications`** folder.
3. Launch KeyFlow from your Applications. It will run silently in your menu bar.

*Note: The application is codesigned with an ad-hoc signature. If macOS Gatekeeper blocks launch on secondary machines, allow execution in System Settings -> Privacy & Security.*
```
